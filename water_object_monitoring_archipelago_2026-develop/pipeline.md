Контекст задачи и критерии — в [`CLAUDE.md`](CLAUDE.md), полный регламент — в [`регламент.md`](регламент.md).

> Обозначения: ✅ — подтверждено (регламент / документация / скриншоты); ⚠️ — предположение или открытый вопрос, нужно подтвердить.

## 1. Что делаем (кратко)

Дрон **«Геоскан Пионер Мини 2»** автономно облетает бассейн, **на борту** нейросетью находит игрушечные кораблики, классифицирует их и считывает идентификаторы, в реальном времени накладывает рамки на видеопоток и пишет лог. Цель — максимум баллов по Таблице 2 регламента (355 баллов) + доп. награда за размер обучающего датасета.

**Объекты:** игрушечные кораблики, корпус у всех **голубой**.
- **Зелёные** накладки/носовой треугольник → **зарегистрирован**.
- **Оранжевые** → **не зарегистрирован**.
- На носу — **ArUco-метка ~3×3 см** (крепят орги позже) → уникальный ID.
- ✅ Кораблики **неподвижны**, других объектов на полигоне нет.

## 3. Итоговая архитектура — всё на борту

```
┌─────────────────────── ДРОН (PioneerOS, NPU) ───────────────────────┐
│  камера → get_cv_frame() → [ YOLO (.rknn) на NPU ] → боксы+класс      │
│                          → [ ArUco (cv2.aruco, CPU) ] → ID           │
│  логика: дедуп/подсчёт, отрисовка рамок, метаданные, лог             │
│  вывод: viewer.imshow("main_camera") → веб-трансляция (реалтайм)      │
│  полёт: pioneer_sdk2 (взлёт → облёт сетки → зависания → rtl → land)   │
└──────────────────────────────────────────────────────────────────────┘
```

Инференс, ArUco, отрисовка, лог и управление полётом — **в одном Python-процессе на дроне**. Ноутбук нужен только для разработки/обучения, в бою не участвует.

## 4. Этап 1 — Сбор датасета

- **Рецепт (✅ пример `camera_record`):** камера зафиксирована вниз → `cv2.VideoWriter` пишет `mp4` в `/home/pioneermini/videos/`, 30 fps → забираем через `Галерея медиа` → нарезаем на кадры. Первый ролик `record_1min.mp4` уже снят командой.
- **Проверить реальное разрешение кадра:** `height, width = camera.get_cv_frame().shape[:2]` (важно для домена обучения и бюджета пикселей ArUco).
- ✅ **Доп. награда = число «естественных» изображений, на которых реально обучалась сеть.** Дубли засчитываются, аугментация — нет (не «естественная»).
- **Стратегия «разнообразие × объём»:** много коротких клипов в разных условиях, из каждого — пачка кадров. Много клипов → разнообразие для боевого прогона; пачки кадров → накрутка засчитанного объёма.
- **Разнообразие набирать условиями:** оба цвета, разные позиции/ориентации, несколько лодок в кадре, блики, у стенок/в центре, разная высота.
- **Домен:** сетка над бассейном **есть и в кадре дрона** → снимать и обучать **с сеткой**. Голубой корпус сливается с водой — различающий признак это оранж/зелёные накладки и носовой треугольник.
- ⚠️ Каждый полёт ограничен ~11 мин батареи — планировать несколько вылетов/зарядов.

## 5. Этап 2 — Разметка

- ✅ Регламент требует факт разметки; **вручную не обязательно**, авто/полуавто разрешено. За баллы разметка не оценивается.
- **Авто-разметка:** цвет (HSV по оранж/зелёному) + форма → bbox; протяжка по видео **трекингом/интерполяцией по ключевым кадрам** (инструмент — **CVAT**). Затем **быстрый ручной QC**.
- ⚠️ ArUco для авторазметки пока не поможет — метки крепят позже. Текущие кадры размечаем по цвету/форме.
- **Классы: 2** — `registered` (зелёный), `unregistered` (оранжевый).
- **Сплит train/val — ПО КЛИПАМ**, не по кадрам (иначе near-duplicate протекут и метрика соврёт). В награду идёт train; val держим чистым и небольшим.

## 6. Этап 3 — Обучение

- Модель: **YOLOv11n** (✅ выбор ML-инженера команды; `pioneer_rknn` поддерживает `yolov8` и `yolov11`; nano — под NPU и реалтайм). Формат разметки YOLO общий для v8/v11.
- ✅ **Дообучение (transfer learning) разрешено — подтверждено оргами напрямую.** Берём предобученную `yolov8n`/`yolov11n` и дообучаем на своём датасете.
- **Аугментация** — для качества (в награду не идёт). ⚠️ **hue-jitter выключить/сузить**: цвет = класс, сдвиг оттенка превратит оранжевый в зелёный и отравит метки. Яркость/контраст/геометрию — можно.
- Баланс классов green/orange ~50/50. Метрика — mAP на чистом val.
- Разрешение входа **640×640** (дефолт `Yolo`).

## 7. Этап 4 — Конвертация в RKNN и загрузка на борт

- ⚠️ Подтвердить target SoC (`rk3566`) и калибровочный набор для INT8-квантизации.

## 8. Этап 5 — Боевой код на борту

Реальные API (`pioneer_sdk2`, `pioneer_rknn`). ⚠️ Псевдокод — уточнить точную структуру возврата `Yolo.run` на дроне.

```python
from pioneer_sdk2 import Pioneer, Camera, ImageViewer, CameraType, ServoCamera
from pioneer_rknn import Yolo
import cv2, json
from cv2 import aruco

pioneer = Pioneer()
camera  = Camera(camera_type=CameraType.MAIN)
viewer  = ImageViewer()
servo   = ServoCamera()
model   = Yolo(model_name="ships_yolov8n", object_thresh=0.5, nms_thresh=0.45)
adict   = aruco.getPredefinedDictionary(aruco.DICT_4X4_50)   # ✅ словарь подтверждён по фото меток оргов (id до 36)

seen, log = {}, []          # aruco_id -> class ; журнал детекций

servo.set_angle(-80)        # камера почти вертикально вниз (макс -80, ≈ надир)
pioneer.arm(); pioneer.takeoff()

for (x, y, z) in WAYPOINTS:                 # газонокосильный облёт сетки бассейна
    pioneer.go_to_local_point(x, y, z, yaw=0)
    while not pioneer.point_reached():
        frame = camera.get_cv_frame(timeout=5.0)
        if frame is None:
            continue
        dets = model.run([frame])                        # NPU: боксы + classId + score
        corners, ids, _ = aruco.detectMarkers(frame, adict)  # CPU: ID на носу
        for d in dets:
            cls = "registered" if d.classId == 0 else "unregistered"
            marker_id = match_marker_to_box(d, corners, ids)  # ближайшая метка в боксе
            if marker_id is not None and marker_id not in seen:
                seen[marker_id] = cls
                save_photofix(frame, d, marker_id)       # фотофиксация в /workspace или Галерею
                log.append({"id": marker_id, "class": cls, "t": pioneer.flight_time()})
            draw_box(frame, d, cls, marker_id)           # cv2.rectangle + cv2.putText
        put_meta_corner(frame, seen)                     # метаданные в углу
        viewer.imshow("main_camera", frame, fps=30)      # → веб-трансляция (реалтайм)

pioneer.rtl()              # возврат на старт (критерий +15)
pioneer.land()
json.dump(log, open("/home/pioneermini/workspace/detections.json", "w"))
```

**Ключевые методы (✅ из документации):**
- Полёт: `arm()`, `takeoff()`, `go_to_local_point(x,y,z,yaw,time)`, `point_reached()`, `set_yaw()`, `rtl()`, `land()`.
- Позиция/препятствия: `get_local_position_lps()`, `get_dist_sensor_data()`, `get_ranger_data()` (5 дальномеров, Mini 2).
- Камера: `camera.get_cv_frame()`, `ServoCamera().set_angle(-90..+30)`, `viewer.imshow(name, frame, fps)`.
- Инференс: `Yolo(...).run([frame])`; загрузка модели — `ModelRegistry().upload_model(...)`.

## 9. Вывод результата (что хотят орги)

1. **Реалтайм-рамки классов** на видеопотоке → рисуем на кадре и отдаём в `viewer.imshow`.
2. **Метаданные в углу** (счётчик, список зарег/незарег с ID) → `cv2.putText`.
3. **Лог-файл** обнаруженного → JSON/CSV в `/workspace` (32 ГБ).
4. **Фотофиксация** каждого объекта → сохранить кадр (Галерея медиа / файл).
- ⚠️ Уточнить у оргов, что именно считается валидной фотофиксацией и в каком виде принимают лог.

## 10. Стратегия по баллам (Таблица 2, 355)

Нейросеть — «несущая»: забирает обнаружение (+60) и классификацию (+120). ArUco — только уникальный ID (+30). Приоритеты:
1. **Точность классификации** (самый дорогой критерий) + **минимум ложных срабатываний** (−10 каждое, влияет и на +20 за стабильность).
2. **Надёжный ArUco-ID** — камеру ставим вниз (`set_angle(-80)`), но метка 3 см с высоты всё равно не читается (вопрос размера, а не угла) → ID читаем **снижением/зависанием** над каждой лодкой (⚠️ стендовый тест высоты чтения обязателен).
3. **Возврат и посадка на старт** (+15) — `rtl()` + `land()`.
4. **Время < 10 мин** (+10) — экономный маршрут облёта.

## 12. Риски

- **Домен сетки/бликов** — обязательно в датасете, иначе ложные срабатывания.
- **Чтение ArUco с высоты** — главный риск потери +30; метка 3 см требует **снижения** над каждой лодкой, что ест время из бюджета 11 мин.
- **Камера / media-server** — источник кадров (`/shmpipe`) может зависнуть (`shm_open failed` → `TimeoutError`). Лечится закрытием других потребителей камеры / `pkill -f media` / ребутом. Всегда корректно звать `camera.stop()`, не держать камеру двумя процессами.
- **Бюджет 11 мин батареи** — весь облёт + чтения + возврат должны уложиться; тестировать целиком.
- **Конвертация в RKNN** — потенциальная просадка точности при INT8; проверить mAP до/после.
- **Антихардкод (2.3.2)** — решение должно быть универсальным; никаких захардкоженных позиций лодок.
