# Нейросеть — версия v1.0 (Архипелаг 2026, мониторинг водных объектов)

Файл: `ships_v2_yolo11n_v1.0.onnx`

## Что это
Детектор маломерных судов (игрушечных корабликов) на кадре RGB-камеры БВС.
Обучен на датасете, собранном облётом полигона (val mAP50 ≈ 0.97).

- Архитектура: **YOLO11n** (Ultralytics), 2 582 542 параметра, 6.3 GFLOPs
- Соответствует коду проекта на коммите **v1.0** (`ver 1.0`), прогон обучения `ships_v2`

## Формат ONNX
- opset: **12**
- Вход:  `images` — `[1, 3, 640, 640]`, RGB, float32, нормализация `/255`, порядок NCHW
- Выход: `output0` — `[1, 6, 8400]`

Выход — «плоская» голова YOLO без встроенного NMS:
6 = 4 (cx, cy, w, h в пикселях 640×640) + 2 значения уверенности по классам.
После инференса нужен NMS.

## Классы
| id | name           | значение                      |
|----|----------------|-------------------------------|
| 0  | `registered`   | зарегистрированное (зелёное)  |
| 1  | `unregistered` | незарегистрированное (оранжевое) |

Имена классов также зашиты в метаданные ONNX (`names`).

## Быстрая проверка
```bash
yolo predict task=detect model=ships_v2_yolo11n_v1.0.onnx imgsz=640 source=<изображение>
```
