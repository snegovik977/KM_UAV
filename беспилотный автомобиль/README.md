# Беспилотный автомобиль

Директория заведена под требование регламента **2.9** — ежедневная сдача архива с тремя
директориями (`беспилотный автомобиль`, `распределительный хаб`, `квадрокоптер`).

Код автомобиля — **чужой трек**, здесь он не планируется:
[docs/DRONE_PLAN.md](../docs/DRONE_PLAN.md) описывает только бортовое ПО квадрокоптера.

## Что отсюда нужно знать треку автомобиля

Обмен между устройствами идёт через **общий протокол**, и он лежит не здесь, а в
[`распределительный хаб/protocol/`](../распределительный%20хаб/protocol/). Это единственный
источник правды для всех трёх устройств: в подзадачах 2.2.4/2.2.6 пакеты шлёт
программа-передатчик, а в финале — настоящий дрон, и **код автомобиля не должен заметить
разницы** (docs/NOTES.md §3).

Точка входа:

```python
import sys; sys.path.insert(0, "<репозиторий>/распределительный хаб")
from protocol import HttpTransport, MessageFactory

transport = HttpTransport("http://<адрес хаба>:5001", src="car").start()
factory = MessageFactory("car")

transport.send(factory.takeoff(origin_x=0.0, origin_y=0.0, origin_yaw=0.0))
for msg in transport.recv():
    if msg["type"] == "station_new":
        ...
```

Пока дрона нет, его роль играет
[`transmitter.py`](../распределительный%20хаб/transmitter.py):

```bash
python "распределительный хаб/transmitter.py" --hub http://127.0.0.1:5001 recon --stations 5
```

Полный список типов пакетов и их полей — в
[`protocol/messages.py`](../распределительный%20хаб/protocol/messages.py).
