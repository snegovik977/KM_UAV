# CV_BPLA

Материалы к соревнованию «Компьютерное зрение в навигации беспилотных роботизированных систем» (Москва, 2026).

## Код

Реализованы **пункты 1 и 2 плана**:

- **2.3.1** — облёт территории по команде: транспорт, система координат, автомат миссии,
  маршрут, запись попыток, диагностика борта. Написан, **полётом не проверен**;
- **2.3.2** — обнаружение электростанций: калибровка камеры, локализация «пиксель → метры»,
  детектор, реестр станций, визуализатор карты. Проверен **без дрона**, сквозным прогоном
  на заглушке.

Подзадачи запускаются по отдельности ключом `--task`: 2.3.1 идёт вообще без детекции.
Пункты 3–4 (статусы, обдув пыли) надстраиваются поверх, см.
[docs/DRONE_PLAN.md](docs/DRONE_PLAN.md).

Маршрут по умолчанию — **прямоугольник от точки взлёта**: вперёд, вбок, назад, обратно
вбок и посадка там же, где взлетели. Стороны и направление задаются в `config.yaml → rect`.

Детектор станций сейчас **классический CV** (`detector.backend: classic`) — он работает
без единого размеченного кадра. Основной путь, YOLO на NPU борта, готов конвейером
в `training/` ([инструкция](docs/YOLO_TRAINING.md)) и ждёт датасета с камеры дрона;
переключение — одной строкой конфига, классический остаётся фолбэком.
Змейка по площади (`route.mode: survey`) и обход трассы по контуру (`route.mode: loop`)
остались и включаются одной строкой.

### Быстрый старт

Пошаговая инструкция по запуску всего и заливке на борт — [RUN.md](RUN.md).

```bash
python3 launch.py --mock --task 2.3.1 --takeoff        # облёт без детекции, борт не нужен
python3 launch.py --mock --task 2.3.2 --takeoff --viz  # разведка + карта станций
python3 launch.py --task 2.3.2 --viz                   # борт: ключ -> заливка -> хаб -> карта -> дрон
```

`launch.py` — пульт: делает то же, что четыре терминала ниже, сам ставит ssh-ключ,
спрашивает про заливку и сносит `__pycache__`. Руками то же самое:

```bash
python3 launch.py --setup                               # проверка окружения + тесты
python3 "распределительный хаб/hub.py"                  # терминал 1
python3 "распределительный хаб/visualizer.py" --hub http://127.0.0.1:5001   # терминал 2
PIONEER_MOCK=1 python3 квадрокоптер/main.py --task 2.3.2 --hub http://127.0.0.1:5001   # терминал 3
python3 "распределительный хаб/transmitter.py" --hub http://127.0.0.1:5001 takeoff     # терминал 4
```

Дрон пройдёт `IDLE → ARM → TAKEOFF → SURVEY → RETURN → LAND → DISARM`, найдёт станции,
разложенные в заглушке, и оставит в `records/` пару `flight_*.mp4` + `flight_*.jsonl`.
Разбор записи: `python3 tools/record.py records/flight_*.jsonl`, прогон перцепции
по ней — `tools/replay.py`.

### Первое, что делать на борту

```bash
scp tools/check_sdk.py pioneermini@172.17.49.2:~/workspace/
ssh pioneermini@172.17.49.2 'cd workspace && python3 check_sdk.py'
```

Адрес нашего борта — **`172.17.49.2`** (проверен на площадке 31.07.2026), а не `10.42.0.1`
из документации Geoscan.

Отчёт закрывает расхождения источников по SDK; результаты переносятся в
`квадрокоптер/config.yaml` туда, где стоит `# НЕ ПРОВЕРЕНО`. Оси и единицы `yaw`
проверяются отдельно — коротким полётом `tools/check_axes.py`. Он прогнан 31.07.2026:
**оси закрыты** (СК автопилота левая: X вправо, Y вперёд — как в раздатке организаторов),
единицы `yaw` остались открытыми, см. `RUN.md` §7.3.
