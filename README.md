# CV_BPLA

Материалы к соревнованию «Компьютерное зрение в навигации беспилотных роботизированных систем» (Москва, 2026).

## Код

Реализован **пункт 1 плана** — подзадача 2.3.1 (облёт территории по команде):
транспорт, система координат, автомат миссии, маршрут облёта, запись попыток
и диагностика борта. Пункты 2–4 (детекция, статусы, обдув пыли) надстраиваются поверх, см.
[docs/DRONE_PLAN.md](docs/DRONE_PLAN.md).

Маршрут по умолчанию — **обход трассы по четырём угловым точкам**: взлёт с площадки «H»
внутри овала, круг по контуру, возврат и посадка на «H». Габариты трассы и сдвиг площадки
задаются в `config.yaml → loop`. Змейка по площади осталась и включается одной строкой
(`route.mode: survey`).

| Путь | Что внутри |
| --- | --- |
| `квадрокоптер/` | бортовое ПО: `main.py` (два потока), `mission.py` (автомат), `flight.py` (адаптер СК и `h_min`), `survey.py` (маршрут: контур или змейка), `config.yaml` (**все** константы), `mock_pioneer.py` |
| `распределительный хаб/` | `protocol/` — единый формат пакетов для всех трёх устройств; `hub.py` — ретранслятор; `transmitter.py` — эмулятор дрона и автомобиля |
| `беспилотный автомобиль/` | чужой трек; [README](беспилотный%20автомобиль/README.md) со входом в общий протокол |
| `tools/` | `check_sdk.py` и `check_axes.py` — диагностика борта, `record.py` — запись и просмотр попыток |
| `tests/` | pytest: протокол, транспорт, оси, контур трассы, покрытие змейки, автомат миссии |

### Быстрый старт без дрона

Пошаговая инструкция по запуску всего и заливке на борт — [RUN.md](RUN.md).

```bash
./setup.sh                                              # проверка окружения + тесты
python3 "распределительный хаб/hub.py"                  # терминал 1
PIONEER_MOCK=1 python3 квадрокоптер/main.py --hub http://127.0.0.1:5001    # терминал 2
python3 "распределительный хаб/transmitter.py" --hub http://127.0.0.1:5001 takeoff   # терминал 3
```

Дрон пройдёт `IDLE → ARM → TAKEOFF → SURVEY → RETURN → LAND → DISARM` и оставит
`flight_*.mp4` + `flight_*.jsonl`. Разбор записи: `python3 tools/record.py flight_*.jsonl`.

### Первое, что делать на борту

```bash
scp tools/check_sdk.py pioneermini@172.17.49.2:~/workspace/
ssh pioneermini@172.17.49.2 'cd workspace && python3 check_sdk.py'
```

Адрес нашего борта — **`172.17.49.2`** (проверен на площадке 31.07.2026), а не `10.42.0.1`
из документации Geoscan.

Отчёт закрывает расхождения источников по SDK; результаты переносятся в
`квадрокоптер/config.yaml` туда, где стоит `# НЕ ПРОВЕРЕНО`. Оси и единицы `yaw`
проверяются отдельно — коротким полётом `tools/check_axes.py`. Он прогнан 31.07.2026:
**оси закрыты** (СК автопилота левая: X вправо, Y вперёд — как в раздатке организаторов),
единицы `yaw` остались открытыми, см. `RUN.md` §7.3.
